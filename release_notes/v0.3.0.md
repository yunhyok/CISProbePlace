## 본딩 좌표로 긴 프로브와 짧은 프로브 자동 분류

- 2변 · 3변 · 4변 배치에서 각 변을 따라 번갈아 놓인 두 본딩 열을 찾아 핀의 변과 프로브 종류를 추정합니다. 판별하기 어려운 핀은 **Undetermined**로 표시합니다.
- **Pin editing → Tips point**에서 제품에 맞춰 팁 방향을 선택합니다. **Toward center**는 바깥 열을 긴 프로브로, **Toward outside**는 안쪽 열을 긴 프로브로 분류합니다. 선택 즉시 그룹과 미리보기에 반영됩니다.
- 기본 그룹은 `LongProbe`와 `ShortProbe`이며 HFSS 모델에 맞춰 이름을 바꿀 수 있습니다. 입력 파일에 지정된 그룹을 자동 분류로 바꾸려면 **Replace input groups**를 켭니다. 핀별로 직접 지정한 그룹이 가장 우선합니다.
- 실제 길이와 팁 위치는 제품 설계값을 사용합니다. HFSS 모델의 본딩 기준점을 원점에 맞추고 **AEDT target**에서 각 변의 실제 회전각을 설정합니다.

## 핀맵에서 프로브 그룹과 방향 편집

- SPD · XLSX · CSV의 본딩 위치를 흰색 핀맵에 표시합니다. 삼각형 색은 HFSS 그룹, 삼각형 끝은 제품 설정에 따른 팁 방향입니다. 핀이 속한 물리적 변은 표의 **SIDE**와 툴팁에서 확인할 수 있습니다.
- 핀을 클릭하거나 **Ctrl + 클릭**으로 개별 핀을 추가 · 해제합니다. **Shift + 드래그**로 사각형 안의 핀을 함께 고를 수 있습니다. 직접 고른 핀은 미리보기 표와 핀맵에서 함께 강조됩니다.
- **Pin editing** 탭에서 선택한 핀의 HFSS 그룹과 CIS 방향을 지정합니다. 그룹별 표시 색도 변경할 수 있습니다.
- CIS 방향을 불러온 전체 배열 기준으로 판정합니다. 예를 들어 왼쪽 핀 하나만 내보내도 왼쪽 회전각이 유지됩니다. 모서리 핀은 직접 방향을 정할 수 있으며 **Auto**로 자동 판정값을 복원합니다.
- 필터를 통과한 핀 전체가 기본 배치 대상입니다. **Place picked pins only**를 켜면 핀맵 · 표에서 직접 고른 핀만 AEDT script에 포함합니다.

## Windows 화면과 설치

입력과 필터, 핀 편집, AEDT 대상을 탭으로 나눴습니다. 차콜 테마와 CIS 센서 패드에 닿는 프로브 모양의 아이콘을 적용했습니다. 설치 파일은 `CISProbePlacementScriptorSetup-0.3.0.exe`입니다.
