## 바뀐 점

- **생성된 probe object를 최상위 `Generated_Group` 아래 NET별 하위 그룹으로 정리.**
  - 기존에 `Generated_Group`이 원본 그룹(`Source_Group`, `LongProbe`, `ShortProbe` 등) 하위에 중첩되던 문제를 수정해 `Model` 바로 아래 최상위 그룹으로 생성합니다.
  - 새로 배치된 object들을 `Generated_Group` 하위에 각 NET 이름별 하위 그룹(`Generated_Group > <NET>`)으로 자동 그룹화합니다.
- **Sigrity SPD에서 공통 `DGND` 핀의 site 자동 인식.**
  - `U1`처럼 한 인스턴스의 신호·전원 핀이 모두 단일 site에 속하는 경우, 같은 인스턴스의 `DGND` 핀도 해당 site에 자동으로 포함합니다.
  - 여러 site가 한 인스턴스에 섞여 있는 경우에도 특정 site의 PWR · SIGNAL 핀 사각형 영역 안에 유일하게 포함되는 `DGND` 핀을 해당 site로 판별합니다.

## 설치

설치 파일은 `CISProbePlacementScriptorSetup-0.3.5.exe`입니다. 이전 버전을 제거하지 않고 같은 폴더에 설치합니다.

설치 파일을 만들 때마다 새로 설치하는 경우, 0.1.4 위에 설치하는 경우, 바로 앞 버전(0.3.4) 위에 설치하는 경우에 프로그램이 시작되는지 자동으로 확인합니다.
