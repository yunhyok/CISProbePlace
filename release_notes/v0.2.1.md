## 도움말 (Help > How to Use, F1)

- Sigrity SPD 가져오기(양식 C) 설명을 새로 정리했습니다: 파일에서 읽는 줄, 좌표 단위 · 주석 같은 파일 규칙, 불러오는 순서, site를 정하는 규칙, 가져온 뒤의 화면, SPD 오류 메시지별 해결 방법.
- 부품 · site 선택 창과 불러온 뒤의 **Input Files** 영역을 실제 화면 그림으로, site가 정해지는 두 가지 경우를 그림으로 보여 줍니다.
- 화면 구성, 파일 불러오기, 문제 해결 항목에 SPD 관련 내용을 반영했습니다.

## 고친 문제

- SPD 파일의 `.Connect` 블록 안에 `*`로 시작하는 주석 줄이 있으면(주석 처리한 핀 연결 포함) 파일 전체를 읽지 못하던 문제를 고쳤습니다. 주석 줄은 건너뜁니다.
- 처음 불러오는 파일이 오류로 실패하거나 SPD 선택 창에서 **Cancel**을 누르면, 고른 파일 경로가 지워져 다시 찾아야 하던 문제를 고쳤습니다. 이제 경로가 남아 있어 파일을 고친 뒤 **Load Inputs**만 다시 누르면 됩니다. 이미 불러온 입력이 있을 때는 전과 같이 그 파일로 돌아갑니다.
- SPD 오류 메시지에 줄 번호 또는 Node 이름을 넣어, 큰 파일에서도 고칠 곳을 찾을 수 있게 했습니다.

## 설치

`CISProbePlacementScriptorSetup-0.2.1.exe`를 실행합니다. 이전 버전 위에 그대로 설치할 수 있습니다.
