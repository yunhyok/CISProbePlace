## 내장 도움말 (Help > How to Use, F1)

- 사용 설명서를 HTML로 새로 작성했습니다. 프로그램 안에서 바로 열리므로 웹 브라우저가 필요 없습니다.
- 입력 파일 양식을 자세히 설명합니다: 좌표 파일과 Allegro pin report 각각의 열, 인정되는 header 이름, 예시, 양식 판별 규칙, 오류 메시지별 해결 방법.
- 작업 흐름, 좌표 중심 보정, HFSS source group 대응, probe 배치 과정, 화면 구성, side 인식을 그림으로 보여 줍니다.
- 목차로 이동하고 본문에서 단어를 찾을 수 있습니다.
- 메뉴 이름이 `Tutorial`에서 `Help`로 바뀌었습니다.

## 고친 문제

- 마주 보는 변의 pad가 같은 X(또는 Y)에 정렬된 배열에서, 모서리 근처 좌표의 SIDE가 잘못 분류되던 문제를 고쳤습니다. 가로 줄과 세로 줄에 동시에 걸린 좌표는 좌표가 더 많이 놓인 줄의 side를 따릅니다.
- 한 줄로만 이루어진 선택에서 끝 좌표 하나만 다른 SIDE로 분류되던 문제를 고쳤습니다.
- 미리보기 표에서 `SIDE` 열로 정렬하면 오류가 나고, 그 뒤로 표와 그림이 갱신되지 않던 문제를 고쳤습니다.
- 좌표가 많은 파일에서 불러온 직후와 script를 만들 때 프로그램이 오래 멈추던 문제를 고쳤습니다. (약 2만 5천 행 기준, 수 분 → 1초 미만)
- X · Y 범위 칸에 값을 입력하는 도중 입력 칸의 focus가 풀려 숫자가 끊기던 문제를 고쳤습니다.
- 소수 자릿수가 많은 좌표에서 가장 바깥 좌표가 기본 선택 범위에서 빠지던 문제를 고쳤습니다.
- net 이름에 `[`, `]`, `?`가 들어 있으면 `*`를 쓴 검색이 맞지 않던 문제를 고쳤습니다.
- COMP_DEVICE가 비어 있는 행이 선택되지 않던 문제를 고쳤습니다. 목록에 `(blank)` 항목이 생깁니다.
- 창이 화면보다 커서 아래쪽 버튼이 가려지던 문제를 고쳤습니다. 화면이 작으면 왼쪽 영역이 스크롤됩니다.
- 미리보기 표의 좌표가 유효 숫자 6자리로 잘려 표시되던 문제를 고쳤습니다.

## 입력 파일 읽기

- header 행이 데이터 행보다 짧은 CSV에서도 header 없는 Source_probe 열을 읽습니다.
- 한 파일에 같은 열로 인정되는 header가 여럿 있을 때, 사용하는 열이 실행할 때마다 달라질 수 있던 문제를 고쳤습니다. 우선순위는 도움말 3.2절에 있습니다.
- 좌표에 `NaN` · `inf`가 있으면 행 번호와 함께 오류로 알려 줍니다.
- 시트 크기 정보가 잘못 저장된 XLSX 파일도 읽습니다.

## 설치

`CISProbePlacementScriptorSetup-0.1.6.exe`를 실행합니다. 이전 버전 위에 그대로 설치할 수 있습니다.
