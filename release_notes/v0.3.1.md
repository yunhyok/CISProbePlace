## 고친 문제

- **해제한 체크박스가 보이지 않던 문제.** 어두운 화면에서 체크를 해제하면 상자가 배경과 거의 같은 색이어서 보이지 않았습니다. **Place picked pins only**, **Replace input groups**, **Automatic probe groups**와 NET · COMP_DEVICE 목록이 해당합니다. 이제 해제 상태는 밝은 테두리의 빈 상자로, 선택 상태는 파란 바탕의 흰색 체크로 표시합니다.
- **왼쪽 탭에 가로 스크롤 막대가 생길 수 있던 문제.** 왼쪽 영역의 폭이 고정되어 있어, 글꼴에 따라 입력 칸의 오른쪽이 잘리고 가로 스크롤 막대가 나타날 수 있었습니다. 이제 왼쪽 영역이 탭 이름과 입력 칸의 폭에 맞춰집니다.
- **처음 열었을 때 Input and filters 탭의 아래쪽이 잘릴 수 있던 문제.** 화면이 충분히 커도 창이 탭의 내용보다 낮게 열려 세로 스크롤 막대가 생겼습니다. 창이 열리는 높이를 세 탭의 내용에 맞췄습니다.
- **도움말 "5. 화면 구성"의 그림.** 번호 표식이 탭 이름을 가리고 **SIDE** 열이 잘려 있었습니다. 표식을 가리키는 항목 옆으로 옮기고 표의 다섯 열이 모두 보이게 했습니다.

좌표 판정, 긴 · 짧은 프로브 분류, 핀 편집, AEDT script 생성의 동작은 0.3.0과 같습니다.

## 설치

설치 파일은 `CISProbePlacementScriptorSetup-0.3.1.exe`입니다. 이전 버전을 제거하지 않고 같은 폴더에 설치합니다.

설치 파일을 만들 때마다 새로 설치하는 경우, 0.1.4 위에 설치하는 경우, 바로 앞 버전(0.3.0) 위에 설치하는 경우에 프로그램이 시작되는지 자동으로 확인합니다.
