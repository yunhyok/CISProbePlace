## 바뀐 점

- **HFSS `SetActiveProject` / `SetActiveDesign` 오류 수정 및 활성 프로젝트·디자인 기본 사용.**
  - **AEDT target**의 `Project` · `Design` 입력 칸을 기본적으로 비워 두어, 별도로 이름을 적지 않아도 HFSS에서 현재 열려 활성화된 프로젝트와 디자인에 바로 실행되도록 변경했습니다.
  - 프로젝트·디자인 이름을 직접 입력한 경우에도 이미 활성화된 대상이면 `SetActiveProject` / `SetActiveDesign`을 다시 호출하지 않아 같은 이름의 프로젝트가 여러 개 열려 있을 때의 `IDispatch ... call failed` 오류를 피합니다. `.aedt` 확장자 제거 및 대소문자 불일치 보정도 함께 처리합니다.
  - 지정한 프로젝트나 디자인이 열려 있지 않을 때는 모호한 `IDispatch` 오류 대신 현재 열려 있는 프로젝트·디자인 목록과 활성 대상을 안내하며, 필수 source group 검증을 디자인 변수 생성보다 먼저 수행해 잘못된 디자인을 변경하지 않도록 했습니다.

## 설치

설치 파일은 `CISProbePlacementScriptorSetup-0.3.3.exe`입니다. 이전 버전을 제거하지 않고 같은 폴더에 설치합니다.

설치 파일을 만들 때마다 새로 설치하는 경우, 0.1.4 위에 설치하는 경우, 바로 앞 버전(0.3.2) 위에 설치하는 경우에 프로그램이 시작되는지 자동으로 확인합니다.
