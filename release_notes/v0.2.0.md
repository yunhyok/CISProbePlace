## Sigrity SPD 좌표 가져오기

- **Browse Coordinate File**에서 텍스트 형식의 `.spd` 파일을 열고 **Load Inputs**를 누르면 DUT 부품과 site를 선택할 수 있습니다. 기본 선택은 0번, 1번, 가장 작은 번호 순입니다.
- `CLK/3`와 `U3_CLK`를 모두 3번 site로 인식합니다. `SITE3`처럼 소속 site가 명시된 부품 인스턴스는 `DGND` 등 공통 net의 핀도 함께 가져옵니다. 소속을 판별할 수 없는 핀은 `(unassigned)`에서 확인할 수 있습니다.
- 선택한 site의 핀 번호와 원래 net 이름을 유지합니다. X · Y 좌표는 mm로 변환하고 해당 핀들의 경계 상자 중심을 원점으로 맞춥니다.
- SPD 좌표는 미리보기 표에서 확인하고 기존 net 필터, HFSS source group 지정, AEDT script 생성에 사용할 수 있습니다. **Change DUT / site**를 누르면 파일을 다시 읽지 않고 다른 부품이나 site로 전환합니다.

## Windows 설치

`CISProbePlacementScriptorSetup-0.2.0.exe`를 실행합니다. 설치 화면에서 설치 폴더를 선택할 수 있습니다.
