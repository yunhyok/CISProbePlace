## 바뀐 점

- **공통 net(GND 등)이 빠진 지그재그 본딩 열의 Long / Short 자동 판정 개선.** Sigrity SPD에서 특정 site만 불러오면 공통 GND 핀 등이 제외되어 본딩 열에 빈자리가 생기거나 짧은 변의 열 간격이 길이에 비해 커질 수 있습니다. 이제 이런 배치에서도 바깥 열과 안쪽 열을 자동으로 인식해 `LongProbe` · `ShortProbe` 그룹으로 바로 지정합니다.
- **핀맵 왼쪽 마우스 드래그 영역 선택.** `Shift` 키를 누르지 않고도 핀맵에서 왼쪽 버튼으로 드래그해 사각형 안의 핀을 한 번에 선택할 수 있습니다. 확대 상태에서도 동일하게 영역 선택이 동작하며, `Ctrl` + 드래그로 선택을 반전하고, 확대 시 화면 이동은 오른쪽 버튼 드래그로 할 수 있습니다. (`Shift` + 드래그는 빨간 범위 경계선 위에서도 영역 선택을 시작합니다.)

## 설치

설치 파일은 `CISProbePlacementScriptorSetup-0.3.2.exe`입니다. 이전 버전을 제거하지 않고 같은 폴더에 설치합니다.

설치 파일을 만들 때마다 새로 설치하는 경우, 0.1.4 위에 설치하는 경우, 바로 앞 버전(0.3.1) 위에 설치하는 경우에 프로그램이 시작되는지 자동으로 확인합니다.
