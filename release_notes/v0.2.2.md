## 고친 문제

- 0.1.4 이하 버전이 설치된 폴더에 0.1.6 ~ 0.2.1 설치 파일을 그대로 설치하면, 프로그램이 `module 'numpy' has no attribute 'short'` 오류 창을 띄우고 시작되지 않던 문제를 고쳤습니다.
- 원인은 이전 버전이 설치해 둔 파일 일부가 폴더에 남아 새 버전이 그것을 잘못 불러온 것입니다. 설치 파일이 이제 설치를 시작할 때 이전 버전의 프로그램 파일(`_internal` 폴더)을 먼저 지웁니다. `_internal` 밖에 따로 보관한 파일은 건드리지 않습니다.

## 이미 오류가 난 경우

`CISProbePlacementScriptorSetup-0.2.2.exe`를 같은 폴더에 다시 설치하면 됩니다. 프로그램을 먼저 제거하거나 폴더를 직접 지울 필요는 없습니다.

## 설치 파일 검증

- 설치 파일을 만들 때마다 0.1.4 위에 덮어 설치한 뒤 프로그램이 시작되는지 자동으로 확인합니다.
- 프로그램이 쓰지 않는 numpy · pandas · lxml · Pillow는 빌드에서 제외해, 빌드하는 PC에 무엇이 설치되어 있든 같은 구성으로 만들어집니다.
