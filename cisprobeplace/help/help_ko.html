 1. 한눈에 보기

probe를 놓을 좌표 목록(CSV 또는 XLSX)을 읽어, Ansys Electronics Desktop(AEDT)의 HFSS에서 실행할 script 파일을 만들어 주는 프로그램입니다. 만들어진 script를 HFSS에서 실행하면, 미리 준비해 둔 원본 probe가 좌표마다 자동으로 복제 · 회전 · 이동됩니다.

그림 1. 전체 작업 흐름. 이 프로그램은 HFSS에 직접 연결하지 않고 script 파일만 만듭니다.

 2. 빠른 시작

  1. HFSS에서 원본 probe를 이루는 object를 모두 Source_Group이라는 group에 넣습니다. probe가 2종 이상이면 종류마다 group을 따로 만듭니다.
  2. 좌표 파일을 만듭니다. 첫 행에 X좌표, Y좌표, Net Name을 적고 그 아래에 좌표를 한 행에 하나씩 적습니다.
  3. 프로그램 왼쪽 위 AEDT Target에 HFSS의 Project 이름과 Design 이름을 입력합니다.
  4. Browse Coordinate File로 파일을 고르고 Load Inputs를 누릅니다.
  5. 오른쪽 미리보기 표와 좌표 그림에서 좌표, SOURCE_GROUP, SIDE가 맞는지 확인합니다.
  6. Generate AEDT Script를 눌러 script(.py)를 저장합니다.
  7. AEDT에서 해당 project와 design을 연 상태로, AEDT의 Run Script 기능으로 저장한 파일을 실행합니다.

가장 간단한 좌표 파일(CSV)은 다음과 같습니다.

X좌표,Y좌표,Net Name
10,5,SIGNAL_A
5,10,SIGNAL_B
0,5,DGND

 3. 입력 파일 양식

입력 파일은 하나입니다. 다음 두 가지 양식을 읽을 수 있으며, 어느 양식인지는 header(열 이름) 행을 보고 자동으로 판별합니다.

양식언제 쓰는가
A. 좌표 파일 (권장)probe 좌표만 직접 정리한 파일. 열 3개(선택 열 포함 4개)면 충분합니다.
B. Allegro symbol pin reportAllegro에서 내보낸 pin report를 그대로 쓰는 경우. 기존 양식과의 호환용입니다.

3.1 두 양식에 공통인 규칙

항목규칙
파일 형식확장자가 .csv 또는 .xlsx인 파일만 읽습니다. .xls, .xlsm, .txt 파일은 Excel의 "다른 이름으로 저장"으로 .xlsx나 CSV로 바꾸어 주십시오.
XLSX의 시트파일을 마지막으로 저장할 때 선택되어 있던 시트 하나만 읽습니다. 좌표가 있는 시트를 선택한 상태에서 저장하십시오.
XLSX의 수식수식이 든 cell은 Excel이 마지막으로 계산해 저장해 둔 결과 값을 읽습니다. Excel에서 열어 저장한 파일이면 문제가 없습니다.
CSV 구분 기호쉼표(,)입니다. 값 안에 쉼표가 들어가면 그 값을 큰따옴표로 감쌉니다.
CSV 문자 인코딩UTF-8(BOM이 있어도 됨) 또는 CP949(한글 Windows Excel의 "CSV (쉼표로 분리)")를 읽습니다.
header 행의 위치첫 행이 아니어도 됩니다. 위에서부터 찾아 필수 열 이름이 모두 들어 있는 첫 번째 행을 header로 씁니다. 그 위에 있는 제목 · 날짜 같은 행은 무시합니다.
header 이름대문자와 소문자를 구분하지 않고, 앞뒤 공백도 무시합니다. 그 밖의 철자는 표에 적힌 이름과 같아야 합니다. (예: Net Name과 NET_NAME은 인정되지만 NetName은 인정되지 않습니다.)
열의 순서 · 추가 열열 순서는 자유입니다. 필요 없는 다른 열이 함께 있어도 되며, 그런 열은 읽지 않습니다.
데이터 행header 행 아래의 모든 행을 읽습니다. 완전히 비어 있는 행은 건너뜁니다.
좌표 값숫자만 적습니다. 단위는 mm로 사용됩니다. 소수점은 마침표이고 1.5e-3 같은 지수 표기도 됩니다.
다음은 오류가 됩니다: 빈 칸, 단위가 붙은 값(1.5mm), 천 단위 쉼표(1,234.5), NaN · inf.
Net 이름비워 두어도 됩니다. 이름이 없는 net은 화면의 NET 목록에 (blank)로 표시됩니다.

Source_probe name 열의 규칙

  • 적은 글자가 그대로 HFSS group 이름이 됩니다. 접두어를 붙이거나 글자를 바꾸지 않으므로, HFSS에 만들어 둔 group 이름과 대문자 · 소문자까지 똑같이 적으십시오. (앞뒤 공백만 제거됩니다.)
  • 이 열의 cell이 비어 있는 행은 기본 group Source_Group을 사용합니다.
  • 이 열이 아예 없으면 모든 행이 Source_Group을 사용합니다.

header가 없는 Source_probe 열

Source_probe name이라는 header가 없더라도, 필수 열 가운데 가장 오른쪽 열의 바로 오른쪽 열에 header는 비어 있고 값만 적혀 있으면 그 열을 Source_probe name으로 읽습니다.

 ABCD
1PIN_XPIN_YNET_NAME(비어 있음)
244.004442.9169U1_VNTGSource_CLS35SE_SBP
343.904542.1669DGNDSource_CLS35S_SBP
주의. 이 규칙 때문에, 그 위치의 열에 메모나 다른 값을 header 없이 적어 두면 HFSS group 이름으로 읽힙니다. 관계없는 내용은 header를 붙이거나 다른 열에 적으십시오.

생성되는 object의 번호

양식 A에서는 데이터 행의 순서(빈 행은 세지 않음)가 1, 2, 3 … 번호가 되고, 이 번호가 HFSS에 만들어지는 object 이름의 앞부분에 쓰입니다. (8. 이름 규칙 참고)

3.5 자동 좌표 중심 보정

파일을 불러오면 프로그램이 모든 좌표를 평행 이동시켜, 좌표 전체를 둘러싼 사각형(bounding box)의 중심이 원점 (0, 0)에 오도록 맞춥니다. 좌표가 원점에서 아주 멀리 떨어져 있어도 따로 손볼 필요가 없습니다.

그림 2. X 범위가 1000~1020, Y 범위가 2000~2060이면 중심 (1010, 2030)을 모든 좌표에서 뺍니다.

  • 중심은 파일에 들어 있는 모든 행으로 계산합니다. 화면에서 일부만 선택해도 중심은 달라지지 않습니다.
  • 미리보기 표, X · Y 범위, 좌표 그림, 생성되는 script의 좌표는 모두 보정된 좌표입니다. 따라서 probe는 HFSS의 원점을 중심으로 배치됩니다.
  • 원본 CSV · XLSX 파일은 수정하지 않습니다.

3.7 입력 파일 점검표

  • 확장자가 .csv 또는 .xlsx인가?

  • 좌표 칸에 숫자만 들어 있는가? (단위 · 쉼표 · 빈 칸 없음)

 4. HFSS 준비: source group

script는 probe를 새로 그리지 않고, HFSS design에 미리 만들어 둔 원본 probe를 복제합니다. 원본은 group에 넣어 두어야 하며, 어느 group을 복제할지는 입력 파일의 각 행이 정합니다.

그림 3. 입력 파일의 행과 HFSS group의 대응 관계 (개념도).

4.1 group 이름 정하기

입력 파일준비할 HFSS group
양식 A, Source_probe name 열 없음 (probe 1종)Source_Group 하나
양식 A, Source_probe name 열 있음그 열에 적힌 이름마다 하나씩 (예: LongProbe, ShortProbe). 빈 칸인 행이 있으면 Source_Group도 필요
양식 B (Allegro)COMP_DEVICE마다 Source_<COMP_DEVICE> (3.3의 변환 규칙)
확인 방법. 파일을 불러온 뒤 미리보기 표의 SOURCE_GROUP 열에 나타나는 이름이, HFSS에 있어야 하는 group 이름의 전체 목록입니다.

4.2 group을 만들 때 지킬 점

  • group 안에는 그 probe를 이루는 모든 object(solid와 sheet)를 넣습니다. group 안의 object가 하나씩 모두 복제됩니다.
  • group은 비어 있으면 안 됩니다. 필요한 group이 없거나 비어 있으면 script는 아무것도 배치하지 않고 오류 메시지를 낸 뒤 멈춥니다.
  • net 이름이 DGND인 좌표에서는, 복제된 object 가운데 sheet object에 Perfect E boundary가 자동으로 부여됩니다. (dgnd처럼 소문자로 적어도 같습니다.)
  • script를 실행하면 object가 많이 만들어집니다. 실행하기 전에 project를 저장해 두면 되돌리기 쉽습니다.

4.3 원본 probe의 위치와 방향

script는 원본을 원점을 지나는 Z축 기준으로 회전 복제한 다음 입력 좌표 (X, Y)만큼 이동합니다. 그러므로 원본은 다음과 같이 놓아 두어야 합니다.

그림 4. 좌표 하나에 probe가 놓이는 과정.

  • 위치: probe에서 좌표에 놓이길 원하는 기준점(pad에 닿는 지점)을 원점 (0, 0)에 맞춥니다. 기준점이 원점에서 벗어나 있으면 그만큼 모든 probe가 어긋나게 배치됩니다.
  • 방향: right side(X가 가장 큰 쪽 변)에 놓였을 때의 방향으로 그려 둡니다. 기본 설정에서 right의 회전각이 0°이기 때문입니다. 다른 방향으로 그렸다면 화면의 회전각을 조정합니다. (7.2)

③COMP_DEVICE Selection양식 B 파일에서 COMP_DEVICE별로 좌표를 고릅니다. 아래 X min ~ Y max는 배치할 좌표 범위이고, Reset Range는 범위를 전체로 되돌립니다.
④NET Selectionnet 이름별로 좌표를 고릅니다. Search로 목록을 좁히고 Select All · Clear All로 한꺼번에 체크하거나 해제합니다.

⑨Log불러오기 · 선택 · 생성 결과와 오류가 기록됩니다.

창의 높이가 부족해 왼쪽 영역이 다 보이지 않으면 왼쪽 영역에 세로 스크롤 막대가 생깁니다. Generate AEDT Script 버튼은 항상 보입니다.

 6. 사용 순서 상세

6.1 대상과 회전각 지정 — ①

  • Project, Design: HFSS에 있는 이름과 똑같이 입력합니다. script는 이 이름의 project와 design을 활성화한 뒤 작업하므로, 실행할 때 그 project가 AEDT에 열려 있어야 합니다. 칸을 비우면 Project1, HFSSDesign1이 쓰입니다.
  • Right / Top / Left / Bottom rotation: side별 회전각(도)입니다. 보통은 기본값을 그대로 둡니다. (7.2)

6.2 파일 불러오기 — ②

  1. Browse Coordinate File을 눌러 CSV 또는 XLSX 파일을 고릅니다.
  2. Load Inputs를 누릅니다. 성공하면 Log에 Input load complete: N pin rows.가 표시됩니다.
  • 불러온 직후에는 모든 net이 체크되고 범위가 전체로 설정되어, 파일의 모든 좌표가 선택된 상태가 됩니다.
  • 파일 내용을 고쳤으면 Load Inputs를 다시 눌러야 반영됩니다.
  • 다시 불러오면 ⑤에서 지정한 임시 group 변경은 모두 사라집니다.

6.3 배치할 좌표 고르기 — ③ ④ ⑧

좌표는 다음 조건을 모두 만족해야 선택됩니다: 해당 COMP_DEVICE가 체크됨(양식 B) · 해당 net이 체크됨 · X와 Y가 범위 안에 있음.

6.5 source group 임시 변경 — ⑤

입력 파일을 고치지 않고 일부 좌표의 HFSS group만 바꾸고 싶을 때 씁니다. HFSS group 칸에 group 이름을 입력한 뒤 버튼을 누릅니다.

버튼동작
Apply to selected rows미리보기 표에서 고른 행에만 적용합니다.
Apply to current coordinates지금 선택된 모든 좌표에 적용합니다.
Clear overrides변경을 모두 취소하고 파일에서 읽은 group으로 되돌립니다.

이 변경은 script를 만들 때만 반영됩니다. 원본 파일에는 저장되지 않으며, 파일을 다시 불러오거나 프로그램을 닫으면 사라집니다.

6.6 script 만들기와 실행 — ⑥

  1. Generate AEDT Script를 누르고 저장할 위치와 파일 이름을 정합니다.
  2. Log에서 Side summary(side별 좌표 수)와 Source group summary(group별 좌표 수)를 확인합니다.
  3. AEDT에서 대상 project와 design을 열고, AEDT의 Run Script 기능으로 저장한 파일을 실행합니다.
참고. 선택을 바꾼 직후에는 선택 결과가 갱신되는 동안 Load Inputs와 Generate AEDT Script 버튼이 잠깐 비활성화됩니다. 갱신이 끝나면 다시 누를 수 있습니다.

 7. CIS side 인식과 회전각

probe는 놓이는 변(side)에 따라 방향이 달라야 하므로, 프로그램이 좌표마다 side를 판별하고 side별 회전각을 적용합니다.

그림 6. 네 변에 좌표가 있는 배열을 인식한 예.

7.1 side를 정하는 규칙

  1. 현재 선택된 좌표만으로 판별합니다. 선택된 좌표 전체를 둘러싼 사각형이 기준이 됩니다.
  2. X 값이 같은 좌표가 2개 이상이면 세로 줄, Y 값이 같은 좌표가 2개 이상이면 가로 줄로 봅니다. (0.000001 mm 이내의 차이는 같은 값으로 봅니다.)
  3. 줄이 기준 사각형의 바깥쪽 30% 띠 안에 있으면 변으로 인정합니다. 왼쪽 띠의 세로 줄은 left, 오른쪽 띠의 세로 줄은 right, 위쪽 띠의 가로 줄은 top, 아래쪽 띠의 가로 줄은 bottom입니다.
  4. 좌표가 그런 줄 하나 위에 있으면 그 줄의 side가 됩니다.
  5. 좌표가 가로 줄과 세로 줄 둘 다 위에 있으면 좌표가 더 많이 놓인 줄의 side가 됩니다. 개수가 같으면 더 가까운 바깥 변, 그래도 같으면 right → top → left → bottom 순서로 정합니다.
  6. 어느 줄 위에도 없는 좌표는 가장 가까운 바깥 변의 side가 됩니다. 거리가 같으면 right → top → left → bottom 순서입니다. 인정된 줄이 전체에 하나뿐이거나 없을 때도 모든 좌표를 이 방식으로 정합니다.
  7. 선택된 좌표가 가로 한 줄뿐이면 모두 top, 세로 한 줄뿐이면 모두 right가 됩니다.
주의. side는 선택된 좌표의 바깥 테두리를 기준으로 정해지므로, 선택을 바꾸면 같은 좌표의 SIDE가 달라질 수 있습니다. 예를 들어 위쪽 변의 좌표만 따로 선택하면 그 좌표들만으로 테두리가 만들어집니다. 배열 전체를 선택한 상태에서 script를 만드는 것이 안전하며, 일부만 선택했을 때는 미리보기 표의 SIDE 열을 꼭 확인하십시오.

7.2 회전각

sideHFSS design 변수기본값화면의 입력 칸
rightCISRotAng_Right0°Right rotation
topCISRotAng_Top270°Top rotation
leftCISRotAng_Left180°Left rotation
bottomCISRotAng_Bottom90°Bottom rotation
  • script는 실행될 때 이 네 변수를 HFSS design 변수로 만들고(이미 있으면 값을 고치고), 회전 복제의 각도로 변수 이름을 사용합니다. 값은 HFSS의 design 변수 목록에서 확인할 수 있습니다.
  • 기본값은 원본을 right side 방향으로 그려 두었다고 보고, right → bottom → left → top 순서로 90°씩 커지도록 정해져 있습니다.
  • 원본을 다른 방향으로 그렸거나 배치된 probe의 방향이 기대와 다르면, 해당 side의 값을 바꾼 뒤 script를 다시 만듭니다. 위아래가 서로 바뀌어 보인다면 Top과 Bottom의 값을 맞바꾸면 됩니다(Top 90, Bottom 270).
처음 사용할 때. 회전 방향은 모델을 보는 방향에 따라 다르게 보일 수 있습니다. 먼저 네 변에서 좌표를 몇 개씩만 골라 script를 만들어 실행해 보고, probe가 원하는 방향을 향하는지 확인한 다음 전체를 배치하십시오.

 8. 생성되는 script가 하는 일

저장되는 파일은 AEDT에 내장된 IronPython으로 실행하는 script입니다. 실행하면 다음 순서로 동작합니다.

  1. 입력한 이름의 project와 design을 활성화합니다.
  2. 회전각 design 변수 4개를 만들거나 값을 갱신합니다.
  3. 필요한 source group이 모두 있고 비어 있지 않은지 검사합니다. 하나라도 문제가 있으면 여기서 멈춥니다.
  4. 좌표마다, 그 좌표의 source group에 든 object 하나하나에 대해 다음을 수행합니다.
    • 그 좌표의 side 변수 각도로 Z축 기준 회전 복제
    • 복제된 object의 이름 변경 (아래 이름 규칙)
    • Group 속성을 Generated_Group으로 지정
    • 좌표 (X, Y)만큼 이동
  5. net 이름이 DGND인 좌표는 복제된 sheet object에 Perfect E boundary를 부여합니다.
  6. 마지막으로, 선택된 좌표 전체를 덮는 사각형 sheet 2장을 만들고 Perfect E boundary를 부여합니다.

이름 규칙

만들어지는 것이름
복제된 probe object<번호>_<Net 이름>_<원본 object 이름>
번호는 양식 A에서는 행 순서, 양식 B에서는 PIN_NUMBER입니다.
DGND 좌표의 boundaryPerfE_<번호>_<Net 이름>

크기는 선택된 좌표 범위의 폭 · 높이의 1.1배입니다. 폭이나 높이가 0이면 그 방향은 1 mm로 만듭니다.
사각형 sheet의 boundaryPerfE_Placement_Bounds
  • 이름에 쓸 수 없는 문자(영문자 · 숫자 · 밑줄 이외)는 밑줄로 바뀝니다. 예: 3번 좌표, net NET/A, 원본 Tip → 3_NET_A_Tip
  • 같은 이름이 design에 이미 있으면 뒤에 _2, _3 …이 붙습니다. 그래서 같은 script를 두 번 실행하면 probe가 한 벌 더 만들어집니다.

 10. 알아 둘 점

  • 좌표의 단위는 mm로 고정되어 있습니다.
  • 프로그램은 입력 파일을 읽기만 하며 고치지 않습니다.
  • 프로그램은 HFSS에 직접 연결하지 않습니다. 배치는 저장된 script를 AEDT에서 실행할 때 이루어집니다.
  • script는 AEDT 안에서 실행하는 IronPython용입니다. 일반 Python으로는 실행되지 않습니다.
  • source group 임시 변경(⑤)과 좌표 선택 상태는 저장되지 않습니다.
